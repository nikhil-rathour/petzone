## 🏆 Achievement
PetZone secured the 1st Runner-up position at Hack The Mountains 5.0, a globally recognized hackathon focused on pushing the boundaries of creativity, innovation, and collaboration in the tech industry.

## 📝 Project Overview
PetZone is a comprehensive platform that connects pet owners with essential pet services including:
- 🏥 Veterinarians
- 🏪 Pet Shops
- 🏠 Adoption Centers

## 🚀 Tech Stack
- **Frontend**: React.js with Vite
- **Styling**: Tailwind CSS
- **State Management**: Redux Toolkit
- **Backend**: Appwrite
- **Form Handling**: React Hook Form
- **Rich Text Editor**: TinyMCE
- **UI Components**: React Bootstrap
- **Icons**: Lucide React & React Icons

## 🛠️ Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/petzon.git
   cd petzon/zone
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

5. **Preview production build**
   ```bash
   npm run preview
   ```
